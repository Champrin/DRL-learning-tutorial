# EV-L-102：CADRL / Decentralized Multiagent Collision Avoidance
- 论文：Decentralized Non-communicating Multiagent Collision Avoidance with Deep Reinforcement Learning（arXiv:1609.07845，2016）。
- 问题设定：
  - 任务：去中心化、不通信的多智能体避障/导航。
  - obs/action：agent 与邻居的 joint configuration（位置、速度）→ collision-free velocity vector。
  - reward：摘要仅述 value network 编码到目标时间的估计；具体奖励函数 UNCERTAIN。
  - 算法：DRL value network；实时查询速度向量，考虑他人运动不确定性。
- 真实机器人实验：摘要只报告 simulation 与 ORCA 对比，未提及真实机器人实验（NO）。
- VERDICT：PASS（CADRL 代表性工作；真实机器人实验按摘要为否）。
