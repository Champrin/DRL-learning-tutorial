# EV-L-007：OpenAI Spinning Up “先自己实现” 建议核查
- CLAIM：OpenAI Spinning Up 明确建议先自己实现核心算法，而不是一开始依赖现成库。
- EVIDENCE：
  - 《Spinning Up as a Deep RL Researcher》页原文：“Write your own implementations. You should implement as many of the core deep RL algorithms from scratch as you can, with the aim of writing the shortest correct implementation of each. This is by far the best way to develop an understanding of how they work…”
  - 同页建议从 VPG/REINFORCE、DQN、A2C、PPO、DDPG 顺序实现，并提醒 “Don’t overfit to existing implementations”，RL libraries 的抽象为复用而非单算法必要。
- COUNTER-EVIDENCE：无。
- VERDICT：PASS。
- CONFIDENCE：HIGH（官方页面原文直接支持）。
