# EV-L-003：TD3 算法事实核查
- CLAIM：Fujimoto et al., arXiv:1802.09477；TD3 是 off-policy；核心为 twin critic + delayed policy update。
- EVIDENCE：
  - arXiv 页作者：Fujimoto, van Hoof, Meger；2018/02/26；正式标题《Addressing Function Approximation Error in Actor-Critic Methods》（TD3 名称常用于算法/社区资料）。
  - 摘要：“builds on Double Q-learning, by taking the minimum value between a pair of critics”；“suggest delaying policy updates”；基础为 actor-critic + DDPG 谱系，属 off-policy 值方法。
- COUNTER-EVIDENCE：无。
- VERDICT：PASS。
- CONFIDENCE：HIGH（twin critic 与 delayed update 均为摘要原文；off-policy 由 Double Q-learning/actor-critic 架构与 DDPG 谱系推论）。
- 快照：references/snapshots/papers/arxiv_1802.09477.html
