# EV-D-001: Gymnasium Env 核心 API

## CLAIM
Gymnasium 1.3.0 的 Env 核心 API 规定：reset() 返回 (observation, info)；step(action) 返回五元组 (observation, reward, terminated, truncated, info)；环境具有 observation_space 与 action_space；gymnasium.make() 用于按 id 创建已注册环境。

## EVIDENCE
- 官方 API 文档 `gymnasium.Env.reset` 签名：`reset(*, seed, options) -> tuple[ObsType, dict[str, Any]]`，文档说明“Resets the environment ... returning an initial observation and info”。
- 官方 API 文档 `gymnasium.Env.step` 签名：`step(action) -> tuple[ObsType, SupportsFloat, bool, bool, dict[str, Any]]`，文档明确返回值为 observation、reward、terminated、truncated、info，并解释 terminated 为 MDP 终止条件，truncated 为 MDP 外部截断条件（如时间限制）。
- 同一页面列出环境属性 `action_space` 与 `observation_space`，分别对应合法动作与观测空间。
- `gymnasium.make(id, ...)` 文档说明其用于创建先前通过 `gymnasium.register()` 注册的环境。
- PyPI 与 GitHub Release 均显示 Gymnasium 当前最新稳定版本为 v1.3.0（发布于 2026-04-22）。
