# EV-D-002: Stable-Baselines3 版本、算法与 check_env

## CLAIM
Stable-Baselines3 当前最新稳定版本为 2.9.0；核心实现算法包括 A2C、DDPG、DQN、HER、PPO、SAC、TD3；额外算法（QR-DQN、TQC、TRPO、Maskable PPO、RecurrentPPO、ARS、CrossQ 等）位于 sb3-contrib 与 SBX；官方提供 `stable_baselines3.common.env_checker.check_env` 工具校验 Gymnasium 兼容环境。

## EVIDENCE
- ReadTheDocs 页面标题显示 “Stable Baselines3 2.9.2a0 documentation”，PyPI 与 GitHub Release 最新 tag 均为 v2.9.0（发布说明提到 gymnasium 1.3.0 支持与 torch>=2.8）。
- 官方 RL Algorithms 页面列出核心算法：A2C、DDPG、DQN、HER、PPO、SAC、TD3，并说明 SB3 Contrib 与 SBX 提供额外算法。
- SB3 Contrib 页面明确列出：RecurrentPPO、TQC、ARS、TRPO、QR-DQN、Maskable PPO、CrossQ 等。
