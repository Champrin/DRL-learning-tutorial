# EV-D-005: NVIDIA Isaac Sim / Isaac Lab 当前状态

## CLAIM
- NVIDIA Isaac Sim 当前最新稳定版本为 6.1.0（GitHub 仓库 isaac-sim/IsaacSim 最新 tag v6.1.0）；官方文档“latest”页面仍为 4.5 时代内容，存在版本提示混乱，建议以 GitHub Release 为准。
- Isaac Lab 当前最新 tag 为 v3.0.0-beta2.patch1（预发布/beta）。
- Isaac Sim 官方支持 ROS 2 bridge extension，文档推荐使用 Humble 与 Jazzy，并实验性支持本地原生 ROS 2 distro。
- Isaac Lab 提供 RL 训练工作流，官方支持 rl_library 包括 SKRL、RSL-RL、RL-Games、Stable-Baselines3（sb3）以及 RLinf（VLA 微调）；环境通过 gymnasium.register()/gymnasium.make() 注册和创建。

## EVIDENCE
- GitHub API 查询 isaac-sim/IsaacSim releases/latest 返回 v6.1.0；IsaacLab releases/latest 返回 v3.0.0-beta2.patch1。
- Isaac Sim 文档 ROS 2 页面写明：“Isaac Sim is connected to ROS through the ROS 2 bridge extension. We recommend ROS 2 Humble and Jazzy with NVIDIA Isaac Sim.” 并提到实验性原生 ROS 2 distro 支持。
- Isaac Lab RL Frameworks 页面列出 supported libraries：SKRL、RSL-RL、RL-Games、Stable-Baselines3、RLinf；并提供 `./isaaclab.sh train --rl_library sb3/rsl_rl/skrl/rl_games ...` 示例。
- Isaac Lab 教程“Registering an Environment”页面说明使用 `gymnasium.register()` 与 `gymnasium.make()`。
